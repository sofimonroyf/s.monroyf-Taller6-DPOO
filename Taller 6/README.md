# Taller 6 - Swing

Diario de restaurantes con interfaz gráfica en Swing.

## Cómo correrlo

1. Importar el proyecto en Eclipse (File → Import → Existing Projects into Workspace).
2. Correr `VentanaPrincipal` (paquete `uniandes.dpoo.swing.interfaz.principal`) como Java Application.

Hay que correrlo desde la carpeta del proyecto para que carguen las imágenes.

## Archivos

- `Taller Swing Restaurantes/`: proyecto de Eclipse
- `diagrama_clases.png`: diagrama UML

La interfaz (`interfaz`) está separada de la lógica (`mundo`); se conectan por la asociación `VentanaPrincipal → Diario`.
